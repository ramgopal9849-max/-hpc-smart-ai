## Permanent Development Rules

1. Security and privacy first.
2. Default mode must remain READ-ONLY.
3. Never modify external websites without explicit authorization.
4. Never expose passwords, OTPs or API keys.
5. Maintain strict business data isolation.
6. Test before production deployment.
7. Keep Home Plumber Cleaning website untouched until its separate integration is approved.
